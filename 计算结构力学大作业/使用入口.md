# 平面桁架软件

推荐双击 [平面桁架计算.exe](平面桁架计算.exe)，已内置计算核心和示例，选择模型后按 F5 计算。

目录版可用 [启动图形界面](程序/run_ui.bat)。两种方式均无需安装 Python 或编译器；目录版须保留“程序”“总控信息”“计算结果”的目录关系。

必做题的 `l`、`h` 为独立几何参数，要求 `l>0`、`h>l/(2√3)`。初始 `l=h=1 m` 仅作演示和校核，原题未给尺寸。七杆为验证算例，不能代替最终选做题。

- [使用说明、总控格式与编译](程序/README.md)
- [课程算法核对](算法说明/课程算法核对.md)
- [校核说明](校核说明.md)；文件校验值见 `SHA256SUMS.txt`

本包包含软件及验证算例。课程报告、手算过程和最终选做题由学生另行补齐。
