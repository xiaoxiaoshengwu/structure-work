## 2. 课程要求的软件核心

第5次 p8-9 的流程可整理为：

1. 读取结构数字化信息并检查模型。
2. 确定节点编号、约束和独立未知位移。
3. 总刚度矩阵清零。
4. 按杆件循环，求杆长及方向余弦、总体坐标下单元刚度矩阵，再按对号关系累加入总刚。
5. 形成外载向量。
6. 将总刚三角化并回代求节点位移。
7. 按杆件恢复局部杆端力/杆件轴力。
8. 输出节点位移及各杆内力。

课件没有指定应采用哪一种具体三角化实现，也没有给出线性方程求解子函数全文。因而选择具有适当数值检查的直接解法是实现决定；不可说课件要求必须采用高斯消元、Cholesky 或某个外部库。程序不应显式求逆矩阵来计算位移。

## 3. 模型、符号和单位

第2次 p10：平面桁架杆件和支座之间铰接，集中力作用在节点，杆件仅承受轴力，结构和载荷在同一平面。程序按线弹性、小位移轴力杆模型实现，这是这些刚度关系的适用前提。

第2次 p24、p28：全局坐标中的力及位移沿坐标正方向取正。每节点只有 `ux`、`uy` 两个平动自由度，不设置刚架用的转角自由度。局部坐标轴从杆左端 i 指向右端 j；局部杆端力也按局部坐标正向取正。

内部推荐统一用 `double`。若以课件的 kN、m 为单位，则 E 为 kN/m²，A 为 m²，EA 为 kN，总刚为 kN/m，位移为 m，杆轴力为 kN。坐标的数值尺度不能与单位约定混用；图形显示比例也不能直接作为物理尺寸。

## 4. 结构数字化与总控信息

第5次 p11-12、p29-31 给出的是下列数据内容，并未规定总控文本文件的标题、分隔符、字段顺序、注释语法或扩展名。

| 课件变量 | 含义 | 实现需注意 |
|---|---|---|
| `n` | 节点总数 | 检查正整数及数组容量 |
| `nc` | 完全固定节点数 | 课程基本公式仅适用于这些节点的两个方向都固定 |
| `m` | 杆件总数 | 检查节点连接关系 |
| `x[n]`, `y[n]` | 节点坐标 | 检查有限值，端点不能重合 |
| `ihl[m]`, `ihr[m]` | 每根杆左右端节点号 | 课件节点号一基，C数组下标零基 |
| `ea[m]` | 杆件 E×A | 必须正且有限；也可输入 E、A 后相乘 |
| `nn` | 独立未知位移数 | 全固定节点模型为 2(n-nc) |
| `dp[nn]` | 全局节点外载向量 | 顺序必须与独立位移完全相同 |
| `r[nn][nn]` | 总刚度矩阵 | 自由度约束处理后再求解 |
| `h[m]` | 杆轴力 | 输出需明确拉压符号 |

课程编排是“先编固定节点，后编可动节点”，同一根杆两端节点号尽量接近（第5次 p11）。这使基本对号公式简单。软件若支持任意节点顺序或单方向约束，应显式建立自由度表；此扩展仍执行相同的对号组集力学关系。

总控文本至少应完整表示：模型名称和单位约定、节点数量/坐标、杆件数量/连接关系/EA（或 E、A）、各自由度约束、节点荷载。若支持非零已知位移，还须提供其数值。文本语法由软件自行定义，并在使用说明中写明；不能将自行选定的文件格式冒称为教师给定格式。

本次软件选定的具体格式是（`#` 开头或其后的内容为注释）：

```text
TRUSS2D 1
NODES n
# id x y fix_x fix_y prescribed_ux prescribed_uy Fx Fy
# 紧接 n 行节点数据；fix=1 表示该方向固定，fix=0 表示自由
ELEMENTS m
# id node_i node_j E A
# 紧接 m 行杆件数据
END
```

编号可任意，但必须唯一，连接所引用的节点必须存在。固定方向的 `prescribed_u` 为已知位移；每节点 `Fx/Fy` 使用全局坐标正向。该格式是软件实现的公开约定，不是课件原有总控文件语法。

## 5. 自由度编号与 location matrix

### 5.1 课件的基本公式

第5次 p14：`nn = 2 * (n - nc)`。未知位移顺序是后部可动节点按节点号递增，每节点先 x 后 y（p17-18）。

对第 k 根杆，`i = ihl[k-1]`，`j = ihr[k-1]`。第5次 p19-22：

```text
i0 = 2 * (i - nc - 1)
j0 = 2 * (j - nc - 1)
```

数学一基位置为 `(i0+1, i0+2, j0+1, j0+2)`；在 C 零基数组中，位置为 `(i0, i0+1, j0, j0+1)`。固定节点得到负对号指示数，其位移不进入未知量。

### 5.2 通用自由度表

定义 `dof[node][0]` 与 `dof[node][1]`，自由方向编号为从零开始的连续整数，约束方向记为 -1。单元 location matrix 为：

```text
LM = [dof[i][x], dof[i][y], dof[j][x], dof[j][y]]
```

在课程的固定节点优先、每可动节点两自由度条件下，LM 恰等于基本公式。逐项判断 `LM[a] >= 0` 可可靠支持左右端任意次序、两端都固定的杆以及单向支座。

## 6. 杆长、方向余弦和单刚

第5次 p25-26：

```text
dx = x[j] - x[i]
dy = y[j] - y[i]
l  = hypot(dx, dy)
c  = dx / l
s  = dy / l
k  = EA / l
```

先检查 `l > 0`，再除以杆长。方向余弦由坐标差直接计算，可处理任意象限的杆；不必反算角度。课件 `clxy[0]` 为 l，`clxy[1]` 为 c，`clxy[2]` 为 s。

第5次 p23-28 中的 `c[i][j]` 是一个 **2×2 块矩阵**，本文为避免与方向余弦 c 混淆称其为 C：

```text
     EA   [ c²  cs ]
C = ----  [       ]
      l   [ cs  s² ]
```

完整的四自由度单元刚度矩阵为：

```text
       [ C   -C ]
ke  =  [        ]
       [-C    C ]
```

因此 `ke = (EA/l) * b^T b`，`b=[-c,-s,c,s]`。单杆 ke 奇异是允许刚体运动的正确性质，不能因此直接拒绝单元；应检查组装并施加边界条件后的结构矩阵。

## 7. 总刚对号累加与边界处理

第3次 p28、第6次 p21-25：杆连接 i、j 两节点时，C 累加到 `Kii`、`Kjj`，-C 累加到 `Kij`、`Kji`。无杆直接连接的节点，相应非对角块为零；固定节点不进入自由位移方程。

一般 LM 组集可以写成：

```text
for a = 0..3:
    if LM[a] < 0: continue
    for b = 0..3:
        if LM[b] >= 0:
            Kff[LM[a]][LM[b]] += ke[a][b]
```

上述是齐次约束 `uc=0` 的课程基本情形。若扩展支持支座沉降等非零已知位移，应以 `Kff uf = Pf - Kfc uc` 处理，不能只删除约束列后忽略其贡献。求解后恢复完整节点位移，约束方向回填已知值。

第5次 p15-16 对仅一个方向受约束的节点演示了辅助约束杆。资料没有给辅助杆的刚度数值；通用程序直接按方向约束自由度可精确处理，不需要假设“无限大刚度”。

可选的支反力输出及平衡检查可用原始全自由度矩阵 `R = Kfull Ufull - Pfull`，或由各杆全局端力累加再减外力。这是验证与软件拓展，课件基础要求核心仍是可动节点位移和杆轴力。

## 8. 求解与内力恢复

第5次 p9 描述三角化和回代。需要在数值分解时检查近零主元/非正主元，报告约束不足、机构或严重病态；不能在奇异矩阵情况下输出貌似正常的结果。保留原始矩阵与载荷，以检查 `Kff uf - Pf` 的残差。

本次 C 程序选用约束缩减后的对角缩放 Cholesky 分解及回代。缩放用于减轻不同刚度量级对数值计算的影响；正定性检查仍不可省略。程序保留完整 K 来恢复支反力。

第2次 p33-34、第4次 p12：

```text
ui_local = c*ux_i + s*uy_i
uj_local = c*ux_j + s*uy_j
delta_l  = uj_local - ui_local
N        = (EA/l) * delta_l
S_i      = -N
S_j      = +N
```

本文规定杆轴力 N 拉正、压负；这与局部杆端力向量中的两个分量不同，不能把左端分量 S_i 误作拉正轴力。若输出应力，还需面积 `sigma=N/A`；仅输入 EA 时无法独立恢复应力。

## 9. 课件代码与表述中需校正的点

这些点是实现审核结论，不是额外的用户指令：

1. 第5次 p27 的调用写作 `ch(int k);`，实际 C 调用应为 `ch(k);`，`int` 只用于函数声明/定义。
2. 第6次 p24-25 的简化 `dor()` 仅判断 `i0>=0`，右端块直接加入；隐含杆件右端是可动节点且两端都固定杆不参与求解。通用程序不能照抄后对负数组下标访问，需分别判断两个端点/四个 LM 值。
3. 第3次 p14、p21 和第4次 p3 以“所有对角大于零”概述单刚；水平或竖直轴力杆的横向对角确实可以为零。一般应说单元矩阵半正定、对角非负，不能据单元的零对角误判错误。约束后的稳定结构 Kff 应为正定。
4. 课件有从数学一基编号转成 C 零基数组下标的写法，尤其 `ihl[k-1]` 与 `r[i-1][j-1]`；实现必须选定统一规则并清楚注释。
5. **第6次 p20 的四杆示例 `δy3` 缺少负号。** p4 的总体 y 向上、节点3和4的竖向载荷均向下。p20 绿色框写成 `δy3=+2(3+2√2)Pl/EA`，应为 `δy3=-2(3+2√2)Pl/EA`。同页蓝色框的杆④内力代入反而已经使用 `-6-4√2`，与正确负号一致。独立按四杆单元组装矩阵求解所得四个位移按 `[ux3,uy3,ux4,uy4]` 排列是 `[2√2,-2(3+2√2),-√2,-(√2+4)]Pl/EA`，对应杆轴力 `[2,2√2,-2,-√2]P`。对于 p4 的 `P=l=1`、`EA=20000`，`uy3=-0.000582842712475 m`。该符号也可用杆④伸长关系核对：`N4=-√2P`、杆④方向 `c=s=-1/√2`，所以 `ux3+uy3-ux4-uy4=-2Pl/EA`；代入其他三个正确位移即得到上述负值。软件应遵守坐标、平衡和伸长关系，不能为匹配该笔误改变正确算法。

## 10. 必做图对软件示例的影响

第6次 p28 与用户附图相同：节点 1、2 的 x/y 都被约束；节点 3、4 为可动节点；共六杆。荷载作用在节点 4，100 kN 沿右下方 45°，另加 20 kN 向右，因此：

```text
Px4 = 20 + 100/sqrt(2)
Py4 =     -100/sqrt(2)
EA  = 2e7 * 0.24 = 4.8e6 kN
```

杆号/连接关系为：① 1-4，② 3-4，③ 2-4，④ 1-3，⑤ 3-2，⑥ 1-2。完全固定的底杆⑥在两端没有支座位移时轴力为零，但仍应保留在模型和输出中。

## 11. 建议的验证范围

- 课程第6次 p4-20 四杆示例：将机算位移/轴力与课件的手算关系比对，验证单刚、组集、内力恢复三段流程。
- 独立单杆轴向算例：验证 `u=PL/EA` 和拉压符号。
- 含单方向支座的稳定桁架：验证自由度约束。
- 输入端点次序反转：轴力结果应相同，局部端力随端点定义变换。
- 两端完全固定的杆：不进入自由方程、输出轴力为零（齐次约束条件）。
- 不足约束/机构、零长度杆、非法节点索引、非正 EA：应返回明确错误。
- 成功求解的案例检查节点平衡、支反力总平衡、位移方程残差。
