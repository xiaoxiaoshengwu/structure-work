# 平面桁架计算软件

上级目录的 `平面桁架计算.exe` 内置计算核心和示例，可独立运行。目录版 `truss_ui.exe` 为图形界面，`truss.exe` 为核心；两种方式均无需 Python 或编译器。目录版须保留两个 exe 及“程序”“总控信息”“计算结果”的目录关系。

## 使用

双击 `run_ui.bat`，选择模型后按 F5 计算。可查看位移、杆件轴力、支反力、校核和原始输出，切换几何图、轴力图及变形图；变形图标明放大倍数。点击杆件可选中对应轴力行，“适应视图”恢复显示比例。

必做题的底杆长 `l` 和顶节点高度 `h` 为独立参数，要求 `l>0`、`h>l/(2√3)`。必做题外轮廓是边长1 m的等边三角形，正确输入为 `l=1`、`h=0.8660254037844386`。原EXE初始 `l=h=1 m` 仅为旧演示值，应修改高度或导入修正后的总控。课件四杆和七杆均为验证算例，七杆不代替最终选做题。

快捷键：F5 计算，Ctrl+O 导入总控，Ctrl+S 导出总控，Ctrl+Shift+S 导出结果。修改模型会清除旧结果；非法模型或约束不足会显示错误。界面位移与杆伸长用 mm，轴力用 kN；文件导出保留完整精度，位移用 m。

双击 `run_all.bat` 可按提示输入 `l`、`h`，生成必做题总控与结果，并计算七杆验证算例。也可在程序目录独立调用：

```text
truss.exe input.txt [output.txt]
truss.exe --required l_m h_m [output.txt]
truss.exe --write-required l_m h_m input.txt
```

方括号表示可省略；省略结果路径时输出到命令行。输入和输出支持完整 Unicode 路径，含空格时加双引号。必做模式同时输出 `h/l` 和 `u/l`；改变形状比会改变杆力，不能只按尺度换算。

## 单位与模型

统一使用 kN、m：E 为 kN/m²，A 为 m²，应力为 kN/m²。全局 x 向右、y 向上，轴力拉正压负。采用小变形、线弹性、理想铰接模型，杆件仅受轴力，荷载施加于节点。

## 总控格式

文本采用 ASCII 关键词与数值，支持科学计数法、UTF-8 BOM 和 `#` 行注释；格式由本软件定义。

```text
TRUSS2D 1
NODES 2
# id x y fix_x fix_y prescribed_ux prescribed_uy Fx Fy
10 0 0 1 1 0.001 0 0 0
20 2 0 0 1 0 0 10 0
ELEMENTS 1
# id node_i node_j E A
100 10 20 2e7 0.01
END
```

- 每节点有 x、y 两个自由度；`fix=1` 为约束，`fix=0` 为自由。已知位移仅写在约束方向，自由方向必须为 0；力和位移按全局正方向取正。
- 节点数 2～1000，杆件数 1～10000。编号须唯一，可不连续、任意排序；杆端引用已有节点。每杆可独立给定 E、A。
- E、A、杆长必须为正，全部数值须有限。缺失字段、重复编号、无效约束、零长度杆、非法连接和机构会报错并返回非零退出码。

此例含支座位移，正确结果为 `u20x=0.0011 m`、`N100=+10 kN`、`R10x=-10 kN`。

## 算法与输出

计算杆长及方向余弦 → 形成单元刚度 → 对号累加总刚 → 处理约束 → 三角分解与回代 → 恢复轴力。采用对角缩放 Cholesky 分解求解 `Kff uf=Ff-Kfc uc`，非正主元拒绝计算；反力由原始总刚恢复。

结果包含自由度映射、杆件几何、位移、轴力、伸长、应力、反力，以及残差、整体合力/合矩和能量校核。自由阶数不超过 20 时附 `Kff` 和修正荷载。课件四杆示例的竖向位移负号校正见 [课程算法核对](../算法说明/课程算法核对.md)。

## 源码与编译

中文注释 C11 源码在 `src`：`truss.c` 为核心；`truss_ui.c`、`truss_ui_io.c`、`truss_ui_view.c` 为窗口、数据调用和绘图，`truss_ui.h` 为共享接口。界面调用同一核心求解器。

已有带 C++ 桌面工具的 Visual Studio 时，双击 `build.bat` 编译核心、`build_ui.bat` 编译界面、`build_exe.bat` 编译单文件版；脚本查找现有 MSVC，使用 `/O2 /W4 /utf-8 /MT`，临时文件自动清理。无人值守可用 `build.bat /batch`、`build_ui.bat /ui`、`build_exe.bat /batch`。exe 静态链接运行库。

Linux 核心可用 `gcc -std=c11 -O2 -Wall -Wextra src/truss.c -lm -o truss`；Windows MinGW 需加 `-municode` 并输出 `truss.exe`。

校核范围见 [校核说明](../校核说明.md)，文件校验值见 `../SHA256SUMS.txt`。完整报告、手算和最终选做题已保存在仓库的“生成交付文件/计算结构力学大作业”目录。
