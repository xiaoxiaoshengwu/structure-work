计算结构力学课程大作业交付说明

1. 计算报告.docx：按提供模板制作；封面学院、专业、姓名和日期留空。
   必做题按边长1 m的等边三角形，l=1 m、h=√3/2 m计算。
   选做题是本报告自选五节点七杆桁架，不是仓库原七杆验证算例。
2. 总控信息：必做题、选做题各一份，可直接读入现有求解器。
3. Windows x64：在“程序”目录双击“运行两题.bat”，或在命令行执行：
   truss.exe "..\总控信息\必做题_总控信息.txt" "..\计算结果\必做题_机算结果.txt"
   truss.exe "..\总控信息\选做题_总控信息.txt" "..\计算结果\选做题_机算结果.txt"
   Windows truss.exe 来自用户上传仓库，未改动；本次未在 Windows 系统运行验证。
4. Linux x86-64：执行 bash 程序/运行两题.sh。提供的 truss_linux 已在本环境验证。
   在程序目录重新编译：gcc -std=c11 -O2 -Wall -Wextra truss.c -lm -o truss_linux
   Windows MinGW 编译：gcc -std=c11 -O2 -Wall -Wextra -municode truss.c -lm -o truss.exe
5. 程序/truss.c：在原计算核心上仅补充中文注释，计算逻辑未改动。
   报告附录A包含该文件的完整文本。本交付采用命令行核心，无图形界面依赖。
6. 单位：力 kN、长度 m、E 为 kN/m²、A 为 m²；轴力拉正压负。
   报告位移表采用 mm；总控与原始机算文件采用 m，换算系数为1000。
7. 打开 Word 后若目录显示提示文字，请右键目录选择“更新域/更新整个目录”。
   PDF 为排版预览；修改报告后以 Word 文档的更新结果为准。
8. 校核资料包含本次实际验证记录及独立复核脚本；后者需 Python 与 numpy，
   仅用于额外复核，运行 C 程序不依赖 Python。
